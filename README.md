# neural-network-from-scratch 🧠

Модель искусственного нейрона на чистом Python (без сторонних библиотек), обучающаяся методом градиентного спуска (Gradient Descent).

## Описание проекта
Нейрон учится предсказывать стоимость поездки на такси по дистанции и времени в пути, самостоятельно подбирая скрытые тарифы на основе исторических данных.

### Структура файлов
* `first_neuron.py` — базовый прямой проход (Forward pass) без обучения.
* `train_neuron.py` — обучение нейрона на одном примере поездки.
* `train_neuron_def.py — полноценное обучение на наборе данных (датасете) с разделением на функции `predict` и `train_neuron`.

## Пример работы (300 эпох)
```text
Эпоха 280: суммарная ошибка = 0.01 руб.
Эпоха 290: суммарная ошибка = 0.01 руб.
Эпоха 300: суммарная ошибка = 0.00 руб.

--- Итоговые настройки нейрона ---
Цена за 1 км: 20.00 руб. (ожидалось 20,00)
Цена за 1 мин: 8.00 руб. (ожидалось 8,00)
```
